## Learning Focus

The intermediate track broadens the workflow toward:

- mixed numeric/categorical data;
- richer preprocessing;
- customer/business datasets;
- health-risk classification exercises;
- segmentation and recommendation;
- text-oriented classification;
- forecasting/prediction;
- multiple-model comparison;
- task-appropriate evaluation.

```text
Problem framing
  ↓
Data audit
  ↓
Preprocessing / encoding
  ↓
EDA + feature preparation
  ↓
Train candidate models
  ↓
Compare metrics
  ↓
Interpret limitations
```

## Important Boundary

The ZIP archives are independent learning artifacts. Their filenames establish the current inventory, but archive internals are not directly reviewable through ordinary GitHub source search.

Medical, financial, hiring, credit, or other high-impact project outputs are educational model exercises and must not be interpreted as validated decision systems without independent datasets, leakage controls, calibration, fairness/error analysis, and domain review.
